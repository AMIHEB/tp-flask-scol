TP Flask + MySQL - mode d'emploi
1. Lance MySQL dans XAMPP (Start sur la ligne MySQL).
2. Double-clique sur run.bat (ou dans VS Code : terminal > run.bat).
3. Ouvre http://127.0.0.1:5000

La base 'scol', les tables et l'exemple E1 sont crees automatiquement.
Si root a un mot de passe MySQL : modifie DB_PASSWORD en haut de app.py.
Pages : /add_user  /users  /choisir  /absences/E1
